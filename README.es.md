# Cayvoy — herramientas TikTok LIVE, app para Windows y apoyo a creadores

[Cayvoy](https://cayvoy.com/) reúne herramientas de interacción en directo y servicios de apoyo a creadores. Cayvoy App para Windows permite trabajar con eventos de TikTok LIVE, widgets de OBS, texto a voz y acciones en juegos interactivos. Encuentra la aplicación Android y más opciones de la plataforma en los enlaces oficiales.

## Descargar Cayvoy App para Windows

- **Recomendado: [Cayvoy Installer — obtener la versión actual](https://cayvoy.com/installer/).** Durante la instalación, el instalador consulta el servicio de versiones de Cayvoy y descarga la versión disponible para Windows. Guarda este enlace permanente para futuras descargas.
- **[GitHub Releases](https://github.com/cayvoycom/cayvoy.com/releases/latest)** — archivos portable EXE, setup EXE e installer publicados, junto con sus sumas SHA-256.
- **Portable** funciona sin una instalación tradicional. **Setup** instala la aplicación en el PC. Los archivos de GitHub con número de versión corresponden a una publicación concreta; para la versión actual se recomienda el enlace oficial del installer.

## Qué puedes hacer con Cayvoy

- Conectar eventos de TikTok LIVE con activadores, acciones y juegos interactivos.
- Añadir widgets y alertas a OBS Studio u otros programas de emisión con fuentes de navegador.
- Preparar contenido multimedia, sonidos y texto a voz TTS para interactuar con la audiencia.
- Descubrir páginas de creadores, donaciones y opciones de apoyo en [cayvoy.com](https://cayvoy.com/).

Las funciones disponibles dependen de la cuenta, el plan y la plataforma. Consulta el sitio oficial para obtener información actualizada y asistencia.
