# Cayvoy — TikTok LIVE alətləri, Windows tətbiqi və yaradıcılara dəstək

[Cayvoy](https://cayvoy.com/) canlı yayımda izləyici ilə qarşılıqlı əlaqə və yaradıcılara dəstək üçün platformadır. Windows üçün Cayvoy App TikTok LIVE hadisələri, OBS vidgetləri, mətndən səsə çevirmə və interaktiv oyun əməliyyatlarını bir araya gətirir. Android tətbiqi və platformanın digər imkanları üçün rəsmi keçidlərdən istifadə edin.

## Windows üçün Cayvoy App endir

- **Tövsiyə olunur: [Cayvoy Installer — cari versiyanı endir](https://cayvoy.com/installer/).** Installer quraşdırma zamanı Cayvoy-un buraxılış xidmətini yoxlayır və hazırda mövcud olan Windows versiyasını endirir. Yeni versiyalar üçün bu daimi keçiddən istifadə edin.
- **[GitHub Releases](https://github.com/cayvoycom/cayvoy.com/releases/latest)** — yayımlanmış portable EXE, setup EXE və installer faylları, SHA-256 yoxlama cəmləri ilə birlikdə.
- **Portable** ənənəvi quraşdırma olmadan işləyir. **Setup** tətbiqi kompüterə quraşdırır. GitHub-dakı versiyalı fayllar həmin buraxılışın nüsxəsidir; cari versiya üçün rəsmi installer keçidi tövsiyə olunur.

## Cayvoy ilə nələr etmək olar?

- TikTok LIVE hadisələrini trigger, əməliyyat və interaktiv oyunlara bağlamaq.
- OBS Studio və brauzer mənbəyini dəstəkləyən yayım proqramlarına vidget və bildirişlər əlavə etmək.
- İzləyici ilə əlaqə üçün media, səs və TTS hazırlamaq.
- [cayvoy.com](https://cayvoy.com/) üzərindən yaradıcı səhifələrini, ianə və dəstək imkanlarını kəşf etmək.

İmkanlar hesaba, plana və platformaya görə dəyişə bilər. Aktual məlumat və dəstək rəsmi saytdadır.
